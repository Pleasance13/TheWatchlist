THE WATCHLIST — VERSION 1

Clean local prototype. This folder is the complete project; there are no nested or duplicate project copies.

Open index.html in a browser.

Included in this baseline:
- Dark minimalist Watchlist UI with list and poster-grid views.
- Physically constructed 3D VHS case with visible depth and spine.
- Mouse-position hover tilt.
- Front/back flip using a separate opaque back face.
- Manual wheel/trackpad scrolling on the VHS back with the scrollbar hidden.
- Movie detail pages using the same VHS case interaction as the grid.
- Interest responses that persist through list, grid, filters, and detail pages.
- Already Seen toggle for the current user.
- History poster grid.
- Settings page and display preferences.
- Square, unrounded VHS artwork/case corners.

This is still a local prototype: no Discord, database, TMDB, or hosting integration is connected yet.
